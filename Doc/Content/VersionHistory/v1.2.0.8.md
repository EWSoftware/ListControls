Version 1.2.0.8 was released on September 10th, 2006.



## Changes in This Release

- Added the `IsBinding` property to the `DataList`
control which can be checked to see if binding is currently taking place so that you can suppress event handlers
that may have unwanted results when binding is happening.
- Fixed the `DataList` control so that if you scroll the list and then
click on a row header when the `DataList` control does not have the focus, the row
associated with the header correctly received the focus.
- Fixed the `BaseComboBox` control so that it correctly raises all
key-related events.
