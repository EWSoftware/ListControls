Version 1.1.0.2 was released on January 2nd, 2006.



## Changes in This Release

- Fixed the `DataList` control so that it works correctly with related
data sources.  The demo has been modified to include an example of using the data navigator in conjunction with a
data list to edit addresses and phone numbers using a data set with a relationship between the two tables that it
contains.
- Added `CaptionVisible`, `CaptionText`,
`CaptionBackColor`, `CaptionForeColor`, and
`CaptionFont` properties to the `DataList` control so that a
caption can be displayed in the list similar to the caption in a `DataGrid` control.
