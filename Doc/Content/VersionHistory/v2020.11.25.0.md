Release notes for version 2020.11.25.0.



## Changes in This Release

- Fixed `BaseComboBoxCell` so that it correctly obtains the graphics
object from the owning data grid view.
- Fixed the layout of images when an image list is used with a
`BaseButtonList`-derived control.
- Added the [](@M:EWSoftware.ListControls.BaseButtonList.SetImageIndex(System.Int32,System.Int32)){prefer-overload="true"}
method to `BaseButtonList` to allow modifying the image index of items in the list control when
using an image list with it.
