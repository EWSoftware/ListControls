Release notes for version 2015.1.19.0



## Changes in This Release

- Cleaned up the code and rebuilt the projects for use with .NET 4.0 and later.
- Added code `ExtendedTreeView` to fix a bug in the base `TreeView`
control that was causing inconsistent checked states when double-clicking on checkboxes on tree view nodes.  The
extended tree view now handles the double click message to ensure the checked state is properly maintained.
- Converted the project from shareware to open source and released it on GitHub.
